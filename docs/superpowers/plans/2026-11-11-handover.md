## Rules that are easy to break

- **The home page must still look like itself.** If a change makes it look different rather than more finished, stop and take the smaller change.
- Never commit an image that shows YouTube thumbnails or book covers. Shots named `local-*` go in `docs/redesign/compare/local/`, which git ignores.
- Never put Aditya's email address in any new file, URL or request. Commits use the repo's configured no-reply identity; do not change git config.
- No em dashes or en dashes in visible copy.
- Never push to `main`. Never run `vercel deploy --prod`: the public link https://fragtaco-portfolio.vercel.app must keep showing the old version until Aditya decides. Previews only.
- yarn needs `COREPACK_HOME="$HOME/.cache/corepack-alt"`.
- The in-app browser pane does not animate while the window is hidden. Use `scripts/audit/cdp.mjs` (see its README). Headless screenshots lag one frame: take a throwaway shot first.
- Usage limits can stop an agent mid-task. Its work is on disk; resume the same agent with a message.
