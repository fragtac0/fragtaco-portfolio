# Round 6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Implementers run on Sonnet at high effort. Every task review and the whole-branch review run on Opus 5.5. Fable is not used. Read the ledger of the previous plan (`.superpowers/sdd/2026-11-11-polish-and-work-page/progress.md`, rulings R2 to R25 and its final block) before starting: its environment notes still hold.

**Goal:** Rebuild the work page (wide rings, real stack icons, shader ground, gallery walls), replace the timeline with a Mars map of Aditya's career, flatten and calm the YouTube wall and the book shelf, warm up the darks, and make every page change a quick liquid-glass reveal.

**Architecture:** Assets first, then two bug fixes, then features. Every page change goes through one module that owns the View Transition. Long form, short form and experience become routes, so the round 5 in-page travel code is deleted. New visuals are pure, unit-tested math modules plus thin React components and small engines (three.js for the gallery, 2D canvas for the map, the `shaders` package for the ground).

**Tech Stack:** Remix 2.17 (Vite 6), React 18, TypeScript strict, Tailwind v4, zod, three.js 0.169, `shaders` 4.x (WebGPU), sharp (dev), vitest, View Transitions API.

**Spec:** `docs/superpowers/specs/2026-11-11-round6-design.md` (section numbers below refer to it). Feedback and answers: `docs/redesign/feedback-log.md`, "Round 6". Where this plan's exact text and the spec disagree, the spec wins; record a ruling.

## Global Constraints

- Node 22, yarn 1 through corepack: prefix every yarn command with `COREPACK_HOME="$HOME/.cache/corepack-alt"`.
- New dependencies allowed: `shaders` (Task 1) only. Nothing else. The gallery is ported source, not a package; `clsx` and `tailwind-merge` stay out.
- No Lenis or any scroll library. No em dashes or en dashes in visible copy, titles or alt text. No serif in the interface (book spines are art and may use it).
- Never commit YouTube thumbnails, Open Library covers, or screenshots that show them (`docs/redesign/compare/local/` is git-ignored for those). Never put the owner's email address in any file, URL or request.
- Never push to `main`. Never run `vercel deploy --prod`. The public link must keep showing the old site.
- Server rendering never touches `window`, `document`, WebGL, WebGPU, canvas, three.js or `shaders`. three.js only through `import("three")`; `shaders` only through a dynamic import in an effect.
- Animate only `transform`, `opacity`, `clip-path`, masks, small filters and shader uniforms. No React state updates per animation frame. Every loop stops when its scene is not visible or the tab is hidden.
- Reduced motion (`prefers-reduced-motion: reduce`) is handled in every task that adds motion.
- Colours, type sizes, text strengths and z-index values come from `app/styles/tokens.css`. From Task 5 on, no hard-coded dark ground or orange glow outside the tokens.
- No file over about 350 lines after its task. Every pure function has a vitest test.
- Third-party source and assets keep their notices: a header comment in ported files and a row in `docs/redesign/credits.md` (source address, licence or terms, what was changed).
- Commits: the repo's configured identity. Message starts with its number (`R40.1: ...`) and ends with a `Co-Authored-By` line naming the model that wrote it. PR bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- Each task ends green: `yarn typecheck`, `yarn lint`, `yarn test`, `yarn build`.
- Browser checks use the production build on :5180 and `scripts/audit/cdp.mjs`, never `yarn dev`. Read timer-driven state by polling inside the page.
- Each part adds one line to the "Build" section of `docs/redesign/feedback-log.md` and a row per change to `docs/redesign/changes-2026-11.md`.
- An untracked `.claude/` directory exists in the repo: leave it, never commit it.

## Review Focus

1. **Rings at odd sizes and counts:** 320 by 568, 390 by 844, 820 by 1180, 1024 by 768, 1440 by 900, 2560 by 1440; 1, 8, 35 and 120 videos per kind. No overlap at any ring phase, nothing with a radius past 0.92 of the half-diagonal. Pinned in Task 8.
2. **Page change interrupted:** a second click during a change, Back during a change, a change into a page whose engine fails. No stuck picture, no lock class left, `usePageSettled` always resolves. Pinned in Tasks 3 and 6.
3. **No WebGPU, no WebGL, reduced motion:** every new visual has a still fallback that shows the same content. Pinned in Tasks 9, 11, 12, 18.
4. **Pointer through a warp:** clicks on the fish-eye wall and the barrel-warped gallery land on the tile under the pointer, corners included. Pinned in Tasks 10 and 12.
5. **Dates and positions on the map:** a moment before the route's first dated point, two moments on one day, today's ping after the last moment, the frame's edges when panning at every zoom. Pinned in Task 17.
